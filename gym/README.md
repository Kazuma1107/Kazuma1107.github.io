# 大阪の完全個室パーソナルジム・面談用モック

Instagramから来た人が、雰囲気・料金・トレーナーを確認して無料体験へ進む導線を検討するための、静的サイトです。

- `index.html`：トップと無料体験フォームの操作見本
- `pricing.html`：料金表示の構成見本（価格は未入力）
- `trainer.html`：トレーナー紹介の構成見本（実在の人物情報は未入力）

ジム名、写真、文章、プラン、お客様の声は実店舗の情報ではありません。画像はこのモックのために生成した架空のコンセプト画像です。フォームは送信も保存もしません。実案件の制作着手や納品物ではなく、2026年10月27日の面談で方向性を確認するための提案資料です。

実制作に進む場合は、ジム名・ロゴ・実際の写真・料金・トレーナー情報・掲載許諾・予約フロー・更新環境を確認し、範囲と契約条件の合意後に制作します。

## 画像生成プロンプトの要旨

- `assets/studio-concept.png`：架空の大阪の小規模・完全個室ジム。暖かな照明、木材とチャコール色、写真左側に見出し用の余白。人・文字・ロゴなし。
- `assets/session-concept.png`：架空の日本人成人とトレーナーによる、初心者向けのスクワット指導風景。自然光、親しみやすい雰囲気。実在の顧客・トレーナー、文字・ロゴなし。

画像は built-in `image_gen` で生成し、プロジェクト内に保存しました。
