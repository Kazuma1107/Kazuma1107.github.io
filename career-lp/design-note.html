CAREER SERVICE LANDING PAGE

相談への「ためらい」を、
安心して進める一歩へ。

20〜30代向けキャリア支援サービスを想定した自主制作LPです。広告から訪れるユーザーが「ここなら自分の悩みを話せそう」と感じられることを、デザインの中心に置きました。

01 / 申し込みの前に、心理的な距離を縮める

ファーストビューでは「転職するかは、話してからでいい。」という言葉を主役に。転職を決断するためのページではなく、今の迷いを相談できる入口として設計しています。相談する二人の自然な表情で、サービス利用時のイメージを補います。

02 / 読む順番を、気持ちの変化に合わせる

共感 → コンセプト → 安心できる理由 → 支援内容 → 職種 → モデルケース → 担当者イメージ → 流れ → FAQ → 相談、の順に配置。特に「何を相談できるか」「申し込んだ後にどうなるか」を、CTAに進む前に確認できるようにしました。

03 / 青と白に、行動の色を一つ

Trust blue
#1854A1Ink navy
#163653Action coral
#DC603D

信頼感のある青、読みやすい紺、余白を作る白を基調にしています。相談CTAには暖色を使い、ページを眺めたときに行動の入口を見つけやすくしました。写真・見出し・本文の強弱で、情報の優先順位を整理しています。

04 / 広告流入を想定したスマートフォン設計

  • スマートフォンでは1カラムに再構成し、見出し・説明・CTAを自然な順序で表示。
  • 画面下の固定CTAにより、読み進めた場所から相談へ移れる導線。
  • 職種はタブ、FAQは開閉式で、必要な情報を選んで読める構成。
  • 動きを抑える端末設定に対応。キーボード操作・フォーカス表示も用意。

05 / 見た目の提案を、触れる形に

ブラウザで確認できるレスポンシブのデザインプレビューとして制作しました。相談ボタンからは、相談テーマの選択・確認・選び直しを体験できます。個人情報の入力、予約の確定、外部への送信は行いません。

制作範囲：構成、コピー、配色、レイアウト、人物画像の生成、PC／スマホの表示設計、操作プレビュー。
実装：HTML / CSS / JavaScript（プレビュー用）。
位置づけ：架空サービスの自主制作。実案件の納品物・集客成果を示すものではありません。
実制作時：支給原稿・ワイヤーフレーム・素材・ブランドルールに合わせて調整します。デザインのみのご依頼の場合は、編集可能な納品データの形式と制作ツールを契約前に合意します。
