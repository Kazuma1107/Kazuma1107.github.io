# 社労士事務所OS — SharePoint / SPFx 導入想定デモ

社労士事務所の情報共有、公文書仕分け、顧問先への公開、給与・手続の進捗を一連の操作で示す自主制作プロトタイプです。すべて架空データです。

公開URL: https://kazuma1107.github.io/sr-office-demo/

## 試せること

1. 「公文書の自動仕分け」で4件の架空PDFを照合します。事業所番号のない書類は要確認、同じ文書キーは重複保留になります。
2. 職員が要確認の割当先を指定し、公開を承認します。自動仕分けだけでは顧問先へ公開しません。
3. 「顧問先ポータル」で職員と顧問先担当者の表示を切り替えます。顧問先表示には、自社の公開承認済み文書だけが現れます。
4. 「給与・手続の進捗」で順序付きの確認工程を進めます。操作履歴とトップ画面の数値も更新されます。
5. 「本番構成と検証事項」でSPFx、SharePoint、Power Automateを使う場合の構成案と、導入前に調べる事項を示します。

## 境界と実装方針

このサイト自体は静的なHTML、CSS、JavaScriptで作った操作デモであり、SPFxパッケージや稼働中のSharePointではありません。SharePoint、Microsoft 365、Cells、弥生給与、Dropboxへの接続、認証、実際のファイル保存、電子申請、給与計算は行いません。画面上の役割切り替えはアクセス制御の説明であり、本番環境のセキュリティ機能ではありません。

本番化では、SharePointサイトとライブラリの権限境界、Entra IDの外部ゲスト管理、SPFx Webパーツ、Microsoft Listsの台帳、Power Automateのフロー、監査と保持設定を要件に応じて検討します。外部製品のAPI、ライセンス、利用規約、外部共有ポリシーを調査してから構成を確定します。

ファイルをローカルの静的サーバーで配信して確認できます。ブラウザを再読み込みすると操作状態は初期化されます。外部への送信はありません。
