# ATLAS CMS — 自社設置CMS 操作コンセプト

自主制作の架空データによる、企業サイト管理CMSのインタラクティブ・プロトタイプ。受託実績や完成した本番CMSを表すものではありません。

- 公開予定URL: https://kazumateraokashoten-spec.github.io/cms-console/
- HTML / CSS / ES modules、外部ライブラリ・分析タグ・フォント・API通信なし。
- 100件のサンプルページ、5カテゴリー。検索・フィルター・ページ送り。
- HTML編集、隔離されたiframeプレビュー、下書き・申請・差し戻し・公開。
- 公開スナップショットと編集中の本文を分離。過去10版を下書きへ復元。
- 管理者・事業情報編集者・閲覧者の操作シミュレーション。
- 問い合わせの担当者・状態・対応メモ、カテゴリー追加。
- 模擬商品API取り込み、取得失敗と再試行、商品ID・版による重複防止。
- localStorageの専用キー `atlas-cms-concept-v1` にのみ保存。初期化はこのキーのデータのみ上書き。
- メール送信・ログイン認証・バックエンド・実際の公開処理はありません。
- 権限のUI切り替えはセキュリティ境界ではありません。本番では全APIで認証・権限を検証する設計です。
- HTMLのプレビューはタグ・属性を検証し、sandbox iframeとCSPでスクリプト・外部通信を制限。

## 確認方法

親ディレクトリを静的HTTPサーバーで配信。`index.html` を開き、ダッシュボードの「操作を体験する」から編集者として下書き保存・申請。ダイアログを閉じて管理者へ切り替え、承認待ち一覧から公開。商品連携は初期状態で「エラーを体験」→「失敗分を再試行」→「同期を実行」の順に確認できます。

## 本番案

自己ホストのStrapi / TypeScript / PostgreSQLを基盤に、支給HTMLのテンプレート、問い合わせ履歴、外部商品APIアダプターを追加。デモの独自UIとStrapi標準管理画面は別物であり、同一UIの実装を保証するものではありません。本番の画面範囲・有償機能・サーバープランは要件整理で確定します。
